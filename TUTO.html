0. Passer à la v2.6 (5 min)

Nouveau : renommer ou supprimer un booster

Renommer = corriger un pseudo : tout est gardé (commandes, gains, paiements, licence, chat).
Supprimer = retirer quelqu'un ajouté par erreur. Ça ne marche que s'il n'a encore aucune commande, aucun paiement et aucun gain, pour ne jamais fausser tes comptes. Pour quelqu'un qui quitte l'équipe, clique plutôt sur Actif pour le passer en Inactif : il disparaît des listes mais son historique reste juste.

Les étapes, dans l'ordre

Supprimer la fausse commande de test de Flare

Le plus simple, dans l'app (v2.4) : Commandes → clique sur l'ID de la fausse commande → bouton rouge Supprimer → confirme. La part de Flare revient aussitôt à la normale.

Sinon, avec Supabase : SQL Editor → New query → colle supabase/reset_commandes_test.sql → Run. Tu vois la liste de toutes les commandes et tu repères l'ID de la fausse. Dans le fichier, enlève les -- devant la dernière ligne, remplace TEST1 par cet ID, puis Run à nouveau.

Si Flare affiche encore un montant en trop, va dans Paiements → « Gains hors commandes » et supprime la ligne de test avec la croix.

1. Première installation (seulement sur un nouveau projet)

supabase.com → New project → nom boost-manager. Génère un mot de passe et garde-le de côté. Choisis la région Europe, puis crée le projet.

SQL Editor → New query : colle schema.sql → Run. Ensuite, une autre New query avec import_historique_discord.sql → Run.

Authentication → Sign In / Providers → Email → désactive Confirm email → Save.

src/config.js contient déjà ton URL et ta clé publique. Ne mets jamais la clé sb_secret_… dedans.

nodejs.org → version LTS → installe en cliquant sur Suivant partout. Laisse décochée la case « Tools for Native Modules ». Redémarre le PC.

Lance 1-INSTALLER.bat, puis 2-TESTER.bat. Dans l'app, clique sur Créer un compte, puis sur Je suis Flowey : devenir admin. Fais-le avant d'envoyer l'app à quelqu'un : le bouton ne marche qu'une fois.

2. Tes boosters

Ajouter un booster et lui donner l'accès

  1. Équipe → formulaire « Ajouter un booster » en bas. Jewex, Dorsal, Flare, Noxio et Vulcaano existent déjà.
  2. Sur sa ligne, clique sur Clé, choisis la durée, puis Générer et Copier.
  3. Envoie-lui le Setup du dossier dist et sa clé, par exemple sur Discord.
  4. De son côté : il installe l'app, clique sur Créer un compte, colle sa clé, puis va dans Mes gains pour indiquer où recevoir ses paiements (PayPal, Skrill, Revolut…).
Il ne voit que ses commandes, sa part et ses paiements : jamais les clients, ta part, ni l'onglet Eldorado. Les boutons +30 j et Révoquer se trouvent dans Licences.

4. Publier une mise à jour

Depuis la v2.6, c'est automatique. Claude envoie les changements dans ton dépôt GitHub boost-manager-updates, GitHub fabrique l'app et la publie tout seul, et toutes les apps installées proposent la mise à jour. Tu n'as plus rien à télécharger ni à lancer.
Pour changer de logo : sur GitHub, ouvre le dossier src → Add file → Upload files → glisse ton image nommée logo.png → Commit changes. N'importe quel format d'image marche.
Les étapes ci-dessous ne servent plus qu'en secours, si tu veux tout faire depuis ton PC.

github.com → Sign up. Retiens ton pseudo.

+ en haut à droite → New repository → nom exact boost-manager-updates → Public → Create repository. Il ne contiendra que les fichiers d'installation, jamais tes données.

À chaque nouvelle version

  1. Extrais le nouveau zip que je t'envoie et remets ton src/logo.png dedans (n'importe quelle taille, le centre sert d'icône). src/config.js est déjà rempli. Le .bat te redemande ton pseudo GitHub si besoin.
  2. Si un nouveau schema.sql est fourni, relance-le dans Supabase (SQL Editor → Run).
  3. Double-clic sur 4-PUBLIER-MISE-A-JOUR.bat, clique sur Oui quand Windows demande l'autorisation, puis tape le numéro de la version, par exemple 2.5.0 (toujours plus grand que le précédent).
  4. La page GitHub s'ouvre. Glisse les 3 fichiers du dossier dist : le .exe, le .exe.blockmap et latest.yml.
  5. Clique sur Publish release.
Chez toute l'équipe, l'app affiche « Nouvelle version disponible — Mettre à jour maintenant », au démarrage ou dans l'heure.

5. Problèmes fréquents

Ce que je voisSolution
« Configuration requise »src/config.js n'est pas rempli, ou tu es dans un ancien dossier.
« Invalid path specified in request URL »L'URL dans config.js doit s'arrêter à .supabase.co, sans /rest/v1/.
Erreur de « lien symbolique » (symbolic link) pendant 3-CREER-EXE ou 4-PUBLIERTu as cliqué sur Non dans la fenêtre Windows. Relance le .bat et clique sur Oui. Pour ne plus jamais avoir cette fenêtre : Paramètres Windows → Système → Pour les développeurs → active le Mode développeur.
« PROBLEME DE LOGO » pendant la création de l'exeTon logo.png fait moins de 256 pixels de côté, ou ce n'est pas une vraie image. Ouvre-le dans Paint → Fichier → Enregistrer sous → Image PNG, avec une image plus grande.
L'app a encore l'icône d'ElectronNormal en mode test (2-TESTER). Sur l'app installée : désépingle puis réépingle l'icône de la barre des tâches.
Photo de profil : « Bucket not found » ou « row-level security »Relance supabase/schema.sql dans Supabase (SQL Editor → Run). Vérifie ensuite dans Storage qu'il y a un dossier avatars marqué Public.
Les couleurs ne changent pasTon logo est en noir et blanc : l'app garde alors son thème bleu et gris. Avec un logo en couleurs, elle prend ses couleurs.
Eldorado bloque sur « Vérification que vous êtes humain »Depuis la v2.3.1, Eldorado s'ouvre dans ton navigateur habituel, où la vérification passe normalement.
« Pas de connexion à la base »Vérifie Internet. Le projet Supabase gratuit se met en pause après environ une semaine sans utilisation : clique sur Restore dans Supabase.
La mise à jour n'arrive pasSur GitHub, la release doit être publiée (pas en Draft), contenir les 3 fichiers, et avoir un numéro plus grand que l'ancien.
Le chat ne se met pas à jour tout seulSupabase → Database → Publications → supabase_realtime : coche messages et notifications.
